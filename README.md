# SocialPulse AI — Prototype

## Run in VS Code

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
   npm start
5. Open http://localhost:3000

## API key safety
The API key that was shared in chat is NOT included in this project.
Revoke that exposed key and create a new one.
Put the new key only in `.env`:

API_KEY=YOUR_NEW_KEY

## Current prototype features
- Live dashboard updates every second
- Percentage analytics
- Sentiment analysis
- Audience by platform
- Trending topics with growth %
- Network analysis
- AI insight feed
- 24H / 7D / 30D controls
- Custom date range
- Responsive dark dashboard
- Reduced-motion support

## Connecting your real API
The exact backend request depends on your API provider. Put the provider-specific request in `backend/server.js`; never expose the secret key in frontend JavaScript.

## Platform logos
The frontend includes the six logo images supplied for this prototype under `frontend/assets/`.
